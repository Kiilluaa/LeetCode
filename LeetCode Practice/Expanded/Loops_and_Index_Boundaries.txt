A loop repeats work. Most bugs in easy problems come from using
the wrong starting index, stopping condition, or update.

The three parts of a for loop
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}
int i = 0       // run once. start at the first valid array index
i < nums.length     // check before every iteration. Stop before the invalid index length
i++     // Move to the next index after the body runs
nums[i]     // use the current index to access the current value

nums = [8][4][9]
index   0  1  2
i visits: 0 -> 1 -> 2 -> stop when i becomes 3

Enhanced for loop
for (int value : nums) {
    sum += value;
}
Use the enhanced loop when you need each value but not its index.
Use an indexed loop when you must compare neighbors,
modify positions, or maintain multiple pointers.

While loop
int i = 0;
while (i < nums.length) {
    sum += nums[i];
    i++;
}

Ex5. Return the sum of only the even values in nums.
public int sumEven(int[] nums) {
    int sum = 0;

    for (int value : nums) {
        if (value % 2 == 0) {
            sum += value;
        }
    }
}
