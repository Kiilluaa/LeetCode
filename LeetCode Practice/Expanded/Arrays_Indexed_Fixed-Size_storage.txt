An array stores values of one type in a fixed number of positions.
Each position has an index beginning at zero.

int[] nums = {4, 7, 2, 9};

index: 0    1   2   3
value: 4    7   2   9

length =4, last valid index = 3

int[] nums = {4, 7, 2, 9};
int first = nums[0];    // 4
int last = nums[nums.length]    // 9
nums[2] = 10;   // [4, 7, 10, 9]

Create result arrays

int[] result = new int[nums.length];
result[0] =  12;

new int[n] creates n positions. Every position initially contains
0. For boolean arrays, the default is false. For object arrays,
the default is null

Ex7. Return the index of the largest value. Assume nums is not empty.

public int largestValue(int[] nums) {
    int currentLargest = 0;
    for (i = 1; i < nums.length; i++) {
        if (nums[i] > nums[currentLargest]) {
            currentLargest = i;
        }
    }
    return currentLargest;
}
