Parameters are named input slots

Method declaration
public int add(int a, int b) {
    return a + b;
}

method call
int result = add(4, 7)

How many Parameters belong inside the parentheses?
Use one parameter for each separate piece of information the method must receive from the caller. Do not create a
parameter for values the method can calculate internally.

**Do not add unnecessary parameters A loop index, running sum, count, or largest-so-far variable
is normally created inside the method because it is working memory, not outside input.

Return sends one result back to the caller
Return a calculated value
public int square(int n){
    int result = n * n;
    return result;
}

Return type and return expression must match

Early return ends the method immediately
Stop as soon as the answer is known
public boolean containsZero(int[] nums) {
    for (int value : nums) {
        if (value == 0) {
            return true;
        }
    }
    return false;
}
The first return true ends the method immediately. The final return false runs only if the loop finishes without finding zero.
