An expression produces a value

Two expressions
int total = 4 + 3 * 2;
boolean large = total > 8;

the expression 4 + 3 * 2 produces 10 because mult happens before add
the expression total > 8 produces true

Arithmetic Operators
+   addition
-   subtraction
*   multiplication
/   division
%   modulo/remainder

**Integer division When both operands are int values, Java discards the decimal part. 7 / 2 is 3, not 3.5

Comparison and Logical Operators
> greater than
< less than
>= greater than or equal
<= less than or equal
== equal primitive values
!= not equal
&& both conditions must be true
|| at least one condition must be true
! reverse true and false

Combining conditions
int age = 20;
boolean allowed = age >= 18 && age < 65;

Increment and compound assignment
Long form          Short form       Meaning
count = count + 1; count++;         Add one.
count = count - 1; count--;         Subtract one.
sum = sum + value; sum += value;    Add value to sum.
score = score * 2; score *= 2;      Double score.
