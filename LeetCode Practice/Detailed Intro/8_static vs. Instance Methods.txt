A class is a blueprint. an object is one created instance

An object can hold its own state
class Counter {
    int value;
    public void increment() {
        value++;
    }
}

Two separate objects
Counter first = new Counter();
Counter second = new Counter();
first.increment();
// first.value is 1; second.value is 0

Instance methods belong to an object
Kind                Called with             Can directly use instance fields?
Instance method     object.method()         Yes
Static method       ClassName.method()      No object is required

Why is main Static
Java needs a method it can call before your program has created any objects. Because main is static, Java can
call Main.main(...) directly through the class.

Simple local program with a static helper
public class Main {
    public static void main(String[] args) {
        System.out.println(square(5));
    }
    public static int square(int n) {
        return n * n;
    }
}

The common compiler error
Static main trying to call an instance method directly

public class Main {
    public static void main(String[] args) {
        int answer = square(5); // error if square is not static
    }
    public int square(int n) {
        return n * n;
    }
}

There are two fixes: make square static, or create a Main object and call object.square(5). For beginner algorithm
practice in a local Main class, the first fix is simpler.
