Access controls who is allowed to call a class method

Access                      Who can use it?                         Beginner use
public                      Code anywhere that can see the class.   LeetCode-required methods; public APIs.
private                     Only code inside the same class.        Internal helper methods and hidden fields.
protected                   Same package and subclasses.            Inheritance-focused code; usually not needed for easy LeetCode.
no modifier                 Only the same package.                  Package-level design; usually not needed for beginner exercises.

Access does not change the algorithm
A public required method and a private helper

public int countEven(int[] nums) {
    return countMatching(nums);
}

private int countMatching(int[] nums) {
    int count = 0;
    for (int value : nums) {
        if (value % 2 == 0) {
            count++;
        }
    }
    return count;
}

Both methods can contain the same kinds of variables, loops, and return statements. The access modifier only
decides where the method may be called from.

Local variables do not use access modifiers
Access modifiers belong on class members, not local variables

public int sum(int[] nums) {
    int total = 0; // correct local variable
    // public int total; // invalid here
    return total;
}

Decision Tree
Choose public or private

Required?   Did LeetCode or another caller need to call this exact
method? Use public.
Helper?     Is the method only used inside the same class to organize
your solution? Use private.
Local?      Is it a variable declared inside a method? Use no access
modifier.
Unsure?     For easy LeetCode, keep the supplied public method and
avoid adding modifiers to local variables.
