The anatomy of a method declaration
public int largestValue(int[] nums) {
    // method body
}

Piece                   Example                     Question it answers
Access modifier         public                      Who is allowed to call this method?
static keyword          not present                 Does the method belong to the class itself or to an object?
Return type             int                         What type of value will be sent back?
Method name             largestValue                What action or answer does this method represent?
Parameter list          int[] nums                  What input values does the method receive?
Method body             { ... }                     What steps will calculate the answer?

Read the first line from left to right
** public: callable from outside the class
int: returns one int
largestValue: method name
int[] nums: receives one integer array named nums

A five question construction process
Build a method declaration
1. Access Is this the LeetCode-required method? Use public. Is it an internal helper? Usually use private.
2. static? On LeetCode, normally keep the provided non-static method.
In a simple local Main program, static helpers can be called directly from static main.
3. Return What exact type is the answer: int, boolean, String, int[], or nothing (void)?
4. Name Use an action or result description in camelCase.
5. Inputs Create one parameter for each separate input value the method needs.

Return type examples
Problem asks you to...                  Return type         Example declaration
return a whole number                   int                 public int countEven(int[] nums)
answer yes or no                        boolean             public boolean containsZero(int[] nums)
return text                             String              public String reverse(String text)
return an integer array                 int[]               public int[] copy(int[] nums)
change data without returning a result  void     public void printValues(int[] nums)

The name should match the returned meaning
Two different promises
public int largestValue(int[] nums)     // returns the value
public int indexOfLargesValue(int[] nums)   // returns the index

** Naming catches bugs If the method is named largestValue but returns an index, the name and
result disagree. A precise name helps you notice the mistake.

A method declaration is not a method call
Kind                        Example                                 Purpose
Declaration                 public int add(int a, int b) { ... }    Defines how the method works.
Call                        int result = add(4, 7);                 Runs the method with argument values.
