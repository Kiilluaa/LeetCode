Assignment direction
Java evaluates the entire right side first. Then it stores the result in the location named on the left.

declaration has two requirements
type - what kind of value will be stored
name - what does this value mean

create and initialize a variable

The first assignment to a newly declared variable is called initialization.
A local variable must be assigned before Java lets you read it.

Common beginner types
int     - whole numbers such as -4, 0, 25
long    - larger whole numbers. write a literal with L when needed. 3000000000L
double  - number that can contain a decimal such as 3.5
boolean - only true or false
char    - one character written in single quotes such as 'A'
String  - Text written with double quotes such as "Text"
int[]   - A reference to an array that contains int elements

Primitive values vs reference values
Primitive - The actual simple value - int, long, double, boolean, char
Reference - A reference that leads to an object or array - String, int[], Solution

Copying a primitive value
int a = 5;
int b = a;
b = 9;
// a is still 5 because b received a copy of the primitive variable

Copying an array reference
int[] first = {4, 7};
int[] second = first;
second[0] = 99;
// both variables lead to the same array, so first[0] is now 99
