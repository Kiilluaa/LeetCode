A complete program you can run locally

public class Main {
    public static void main(String[] args) {
        int[] nums = {4, 9, 2, 7};
        int answer = largestValue(nums);
        System.out.println(answer);
    }

    public static int largestValue(int[] nums) {
        int largest = nums[0];
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > largest) {
                largest = nums[i];
            }
        }
        return largest;
    }
}

The Java runtime begins by calling main. The main method creates inpuht, calls largestValue, receives the returned
result, and prints it. 

Step 1 - Java runtime, calls main
Step 2 - main, creates the nums array
Step 3 - main, Calls largestValue(nums)
Step 4 - largestValue, calculates and returns 9
Step 5 - main, Stores 9 in answer and prints it


LeetCode supplies the starting code

class Solution {
    public int largestValue(int[] nums) {
        int largest = nums[0];
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > largest) {
                largest = nums[i];
            }
        }
        return largest;
    }
}

LeetCode has its own hidden test program. It creates a Solution object, calls your required method with many test inputs,
and checks the returned answer. That is why you normally do not write main, read keyboard input, or print the final answer.

** On LeetCode keep the class and method declaration exactly as provided. Write your variables and logic inside the method body **


Printing is not the same as returning

Print - Shows a value to a person or console
        Ex. System.out.println(answer);
Return - Sends a value back to the code that called the method
        Ex. return answer;
