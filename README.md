## Learning Approach

My general process is:

1. Understand the problem and expected return value.
2. Build a correct solution using concepts I already understand.
3. Test edge cases.
4. Analyze time and space complexity.
5. Simplify unnecessary logic.
6. Improve the algorithm when a more efficient pattern is available.
7. Revisit similar LeetCode problems to reinforce the pattern.

The focus is on developing the ability to reason through unfamiliar problems rather than memorizing individual solutions.
